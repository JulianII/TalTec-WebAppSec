# TalTec-WebAppSec
### Web-Based Secure Password Manager

# Planned scope
**goal:** 
Design and create a secure web-based password manager.

**deliverables:** 
- A website
- A Browser extension
- A backend API
- A database

**tasks:** 
- Authenticate towards the API
- Edit, add and delete credentials
- generate secure passwords
- manage sessions
- encrypt and decrypt credentials
- Control user access
- Defend against common web application attacks
- Use TOTP MFA
- Monitor and Log all services


**exclusions:**
- DDOS protection
- Any Load balancing tasks
- High availability infrastructure
- Developing own MFA
